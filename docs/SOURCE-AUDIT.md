## Status and evidence

The directory uses three editorial status values:

- `published work`: a readable public publication, catalogue, course, directory or browser tool. This label does not certify every claim or imply the organisation described is operating.
- `proposal`: planning, programme or implementation concepts whose operation has separate requirements.
- `prototype`: a demonstration, research model or incomplete workbench whose limits are stated in its summary or source.

Sovereign Capacity Lab provides editable scenario calculations. Model outputs retain the source's assumptions and dates. Aura Genesis, Geode, Truth Engine and health-related work retain their research and proposal status. P4A Membership's public interface is a fictional preview and accepts no real memberships or payments.

The reviewed Outreach CMS seed contains 18 projects, 41 discovery routes, 257 reference places and 83 Queensland international links. It contains zero confirmed resident contacts and zero participating communities. Discovery routes are not a mailing list, an introduction or evidence of partnership.

C-Hours recognise verified voluntary human contribution. They have no fixed monetary conversion. Paid work, money and outcomes remain separate records.

## Reused publishing patterns

The inspected source projects establish the following patterns:

- Australian English, plain explanations and no em dashes in newly authored campaign copy.
- GitHub Pages, relative links, a `.nojekyll` file and reproducible generation where needed.
- Complete all-pages navigation, readable sitemap, previous and next links, a return-to-top control, keyboard access and reduced-motion support.
- Per-page descriptions, canonical links, social sharing metadata, author credit, `en-AU`, structured metadata and source links.
- Generated raster concept imagery labelled as such, with prompts, attribution, hashes and rights retained in provenance records.
- PNG and ICO favicon assets in the more recent Infinity Creative Workshop pattern.
- Substantive build dates kept separate from repository creation, later housekeeping updates, evidence dates and events.

The original Redlands source supplies a cream, forest-green and coral editorial family. Luke subsequently chose more purple, actual Redlands photographs and full-width hero imagery. The current interface follows the P4A purple family and uses credited real location photographs. Recent Infinity Creative Workshop and Joyful Responsible Abundance sites supply additional dark visual precedents. Source projects' generated imagery remains source material; it is not substituted for the current real-photo direction.

## Licence and crawler policy

Preserve the Strange But True Public Source Licence terms and attribution. It is a public source licence, not an open-source licence. The canonical inspected licence revision is [Strange But True, 30 June 2026](https://github.com/auraofintelligence/strange-but-true/blob/b953391fc5596c2e66b3535c45ef6cf6175baa23/LICENCE.md). Luke requires successful negotiation and separate written licence and commercial agreements for commercial or political use of his original work. The [permissions page](https://auraofintelligence.github.io/redlands-mayoral-campaign/licensing.html) introduces that process. Third-party material retains its own rights. Linking a source grants no additional reuse, endorsement or training rights.

The current Household Bill Check crawler pattern permits general and search discovery and asks GPTBot, ClaudeBot and Google-Extended not to collect the project. Only the [host-root robots file](https://auraofintelligence.github.io/robots.txt) controls the shared GitHub Pages hostname. A project-level `robots.txt` alone does not impose that policy at a subdirectory address. Any host-root change must add the new project's narrow paths while preserving existing directives.

## Public data boundary

This directory includes public project descriptions, public destinations and source provenance. It does not contain private contact records, household documents, credentials, local paths, raw autobiographical intake, identity records or third-party personal details. Source material remains linked in context. A project relationship does not establish endorsement, partnership, appointment or campaign participation.

Future updates should inspect the new source revision, revise the relevant summary or status and retain the source trail. Do not advance a source date merely because the campaign site was rebuilt.
